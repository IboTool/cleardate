# ClearDate — Candidate Drug Library

Legend: **QT** = QT/torsades relevance · **2D6-i** = CYP2D6 inhibitor · **2D6-s** = CYP2D6 substrate · **MBI** = mechanism-based inhibitor · **5-HT** = serotonergic · **MAOI** = MAO inhibition · **Ind** = enzyme inducer
